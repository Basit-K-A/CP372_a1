## Installation

1. Clone the repository:
```bash
git clone https://github.com/Basit-K-A/CP372_a1.git
```

2. Navigate to the project directory:
```bash
cd CP372_a1
```

3. Compile the Java source files:
```bash
javac src/*.java
```

## Usage

To run the main program:
```bash
java -cp src/ <MainClassName>
```

Replace `<MainClassName>` with the appropriate main class.
